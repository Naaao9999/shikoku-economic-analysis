# 地域間産業連関表を活用した四国地域の長期的分析 (1985–2005)

## Project Overview
1985年から2005年までの20年間（計4時点）の地域間産業連関表を独自に整備・統合し、四国経済の構造的変容を解明する研究プロジェクトです。
産業連関分析による構造記述と、MCMC（階層ベイズ）を用いた統計的推論、さらにGeoPandasによる空間統計の動的可視化を組み合わせ、バブル期から低成長期に至るサプライチェーンの変容を定量化しています。

## 地域間産業連関表とは？
### 地域間産業連関表の概要と本分析のデータ特性
1. 産業間の依存関係を記録した「行列データ」
   
産業連関表は、一定期間（通常1年間）における産業間の取引を一つの行列にまとめた統計です。
* 列（縦方向）： 各産業が生産のために、どの産業から原材料やサービスを **「投入（購入）」** したか。
* 行（横方向）： 生産した品目を、他の産業や消費者にどのように **「産出（販売）」** したか。

この表を用いることで、ある産業への需要が他の産業にどれほどの波及効果を及ぼすかを、行列演算によって定量的に算出することが可能になります。

2. 「地域間」という空間情報の付加

本研究で扱う「地域間」モデルは、通常の産業連関表に「空間（地域）」の軸を加えたものです。 例えば「四国の建設業」が資材を調達する際、それが「四国内の製造業」からなのか、あるいは「近畿や中国地方の製造業」からなのかという、地域を跨ぐサプライチェーンの構造を詳細に記述しています。

わが国では、通常の産業連関表を総務省及び各都道府県、一部の政令指定都市などが公的データとして公表しています。また、地域間産業連関表は経済産業省が2005年まで公表しており、本研究では公表を中止する2005年までを分析対象として分析しています。

## 本分析の価値

産業連関表から計算される取引関係をAPL（平均波及距離）と呼ばれる手法で可視化することで、従来の統計値（生産額の増減など）だけでは見落とされる「経済のつながり」を分析します。さらに、計算されたAPLを階層ベイズ分析で要因分析することで、APLの短縮・伸長がどのような要因で発生したのかを検討します。

### 1. サプライチェーンの「質の変化」を捉える
APL（平均波及距離）を用いることで、単なる取引額ではなく「産業間の繋がりの深さ」を測定します。
これにより、「生産額は維持されているが、地域内での波及プロセスは短縮化（空洞化）している」といった、統計の表面には現れない構造的な脆弱性を把握できます。
四国地域において、どの産業が「地域経済のハブ」として機能し、どの産業が域外依存を強めているかを特定することで、効果的な産業誘致・育成戦略の立案に貢献します。
 
### 2. 政策の「打ち手」を最適化する（階層ベイズの意義）
階層ベイズモデルにより、波及効果の変化を「地域要因」と「産業要因」に分離して推定します。
これにより、経済停滞の原因が四国という地域のインフラや地理的制約にあるのか、あるいはその産業自体が全国的に抱える構造課題にあるのかを科学的に切り分けられます。

この分析結果は、自治体が自らの努力で改善可能な領域（交通アクセスの整備など）にリソースを集中すべきか、国レベルの産業政策と連携すべきかを判断するための根拠となります。

### 3. 最新手法と歴史的エビデンスに基づく政策的示唆
本研究では、80〜90年代の分析手法では実現できなかった「階層ベイズによる要因分解」や「APL（平均波及距離）による測定」を適用しています。過去の政策や経済ショックが、長期的にどのように地域の産業構造を形成したかを評価します。
古いデータを最新のデータサイエンス（MCMC等）で再解釈することで、決定論的な指標だけでは見落とされていた「地域要因」と「産業要因」の効果を確率的に分離し、より頑健な因果推論を行っています。

### 4. 小地域でもロバストな分析を行うという、産業連関分析・地域経済分析への方法論的貢献
本研究は、APLと階層ベイズモデルを組み合わせた新しい分析枠組みを提示することで、産業連関分析や地域経済分析の分野に方法論的な知見を提供します。統計のぶれが大きく不確実性の大きい小地域分析においても安定した推計を行うツールを提供します。

## Research Background & Novelty
* **20年間にわたる長期時系列分析**
  地域間産業連関表を用いた分析の多くは単一時点の断面的分析ですが、本研究では経済産業省が公表を中止するまでの20年分の一貫した産業部門統合を行い、時系列での構造比較を実現しました。この規模の長期分析は、先行研究においても類を見ない取り組みです。
* **産業間結合の質的評価**
  単なる取引額の推移ではなく、後述するAPL（平均波及距離）を用いることで、産業間の「繋がり方」の変容を抽出しています。
* **統計モデリングの導入**
  決定論的な分析に留まらず、PyMCによる階層ベイズモデルを導入。地域固有の要因と全国的なトレンドを分離して推定しています。

## Methodologies

本プロジェクトは、データエンジニアリングから統計モデリング、可視化までを以下の2つのNotebookで完結させる構成となっています。

### 1. データクリーニングと部門統合 (`01_data_preprocessing.ipynb`)
20年間の時系列比較を可能にするため、産業分類の変遷（日本標準産業分類の改定等）を吸収するデータエンジニアリングを行います。

* **長期時系列の統合**
    昭和60年(1985)、平成2年(1990)、平成7年(1995)、平成17年(2005)の計4時点の表を対象に、時点間で異なる部門分類を一貫した「共通統合部門」へマッピングします。
* **データクレンジング**
    経済産業省の原表に含まれる装飾用セルや空白行、結合セル等をプログラムで自動処理し、分析用行列Excelを生成します。
* **整合性検証**
    列差分検出アルゴリズムを実装し、全時点における部門構成の完全な一致を確認することで、次工程の統計分析の精度を担保します。

### 2. APL計算・統計モデリング・可視化 (`02_apl_analysis.ipynb`)
整備された行列データを用い、APLの算出から要因分析、GIS出力までを統合的に実行します。
#### ① APL (Average Propagation Length) の算出
産業間の「経済的な距離」を測定します。レオンチェフ逆行列 $B = (I - A)^{-1}$ を用い、生産波及が何段階の取引を経て伝わるかを定量化します。
> **APLの定義（行列形式）**
> 投入係数行列を $A$ としたとき、APL行列 $L_{APL}$ は以下の式で算出されます。
> 
> $$L_{APL} = [B \cdot (B - I)] \oslash [B - I]$$
> 
> ※ $\oslash$ は要素ごとの除算（アダマール除算）を指します。分母が0となる要素（波及がない経路）を適切に処理するロジックを実装しています。

#### ② 階層ベイズモデリングによる要因分解
**PyMC (MCMC)** を導入し、APLの変動を以下の3つの効果に分離して推定します。
* **地域要因 (Region Effect)**: 四国特有、あるいは他地域固有の構造。
* **産業要因 (Sector Effect)**: 特定産業が全国的に抱える技術的特性。
* **年次要因 (Year Effect)**: バブル崩壊や景気後退などのマクロ経済トレンド。
これにより、特定の変化が「四国という場所」の固有要因なのか、あるいは「産業全体の構造的変化」なのかを確率的に判定します。

#### ③ 空間統計（GIS）を活用した動的可視化
**GeoPandas** を用い、分析結果を日本地図上にマッピングします。
* **高品質な地図生成**: 離島（沖縄県等）のインセット表示や、特定地域へのズーム、凡例の最適配置などをコードで制御。
* **動的アニメーション**: `imageio` を用い、20年間のサプライチェーン変容を時系列GIFアニメーションとして出力します。地場産業の「空洞化」や「集積」のプロセスを視覚的に提示します。

## What did we find?（詳細は公表する予定の論文にて）
* **全国的にAPLの長さ（＝サプライチェーンの長さ）は徐々に短縮している** →技術や交通の効率化の影響？
* **四国地域で輸出（地域外から稼ぐ力）が強い造船業や製紙産業は、全国の同産業に比べて短いサプライチェーンを持っている** →集積の影響？
