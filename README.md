# Shikoku Economic Analysis (1985–2005)

## Project Overview
1985年から2005年までの20年間（計4時点）の地域間産業連関表を独自に整備・統合し、四国経済の構造的変容を解明する研究プロジェクトです。
産業連関分析による構造記述と、MCMC（階層ベイズ）を用いた統計的推論を組み合わせ、バブル期から低成長期に至るサプライチェーンの変容を定量化しています 。

## 本分析の価値

本リポジトリの分析手法を用いることで、従来の統計値（生産額の増減など）だけでは見落とされる「経済の健康診断」が可能になります。

### 1. サプライチェーンの「質の変化」を捉える（APL分析の意義）
単に取引額を追うのではなく、APL（平均波及距離）を用いて「産業間の繋がりの深さ」を測定します。
* **課題解決**: 「生産額は維持されているが、実は地域内での波及プロセスが短縮化（空洞化）している」といった、統計の表面に現れない構造的な脆弱性を早期に検知します 。
* **利点**: 四国地域においてどの産業が「地域経済のハブ」として機能し、どの産業が域外依存を強めているかを特定し、効果的な産業誘致・育成戦略の立案に貢献します。

### 2. 政策の「打ち手」を最適化する（階層ベイズの意義）
階層ベイズモデル（交差効果モデル）を導入することで、波及効果の変化を「地域要因」と「産業要因」に分離して推定します 。
**課題解決**: 経済停滞の原因が「四国という地域のインフラや地理的制約」にあるのか、それとも「その産業自体が全国的に抱える構造課題」にあるのかを科学的に切り分けます 。
**利点**: 自治体が「自らの努力で改善可能な領域（交通アクセスの整備など）」にリソースを集中投下すべきか、国レベルの産業政策と連携すべきかの判断指針（エビデンス）を提供します 。

### 3. 社会インフラ・生活基盤の維持戦略（応用可能性）
土木計画学的な視点から、経済波及の低下が住民のアクセシビリティ（例：医療サービスへの到達性）に与える影響の評価へと繋げます 。
* **利点**: 人口減少下における限られた行政予算の中で、どの地域のインフラを優先的に維持・更新すべきかという空間的な優先順位付けを可能にします 。

## Research Background & Novelty
* **20年間にわたる一貫した長期時系列分析**
  S60からH17に至る4時点を、独自の部門統合によって一貫した形式で比較。この時代をこれほど長期間にわたり、かつ詳細な手法で追跡した分析は、先行研究においても例のない取り組みです。
* **APLを用いた「結合の質」の定量化**
  取引金額の増減という表面的な指標ではなく、APL（平均波及距離）によって「サプライチェーンの深さ」そのものを抽出し、経済の変質を捉えています。

## Methodologies
* **APL (Average Propagation Length)**: 産業間の経済的な距離（サプライチェーンのステップ数）を測定。
* **Localization Process**: 輸入除去処理を施した国産化行列の構築。 $$A_{domestic} = \text{diag}(d) A_{total}$$
* **Hierarchical Bayesian Modeling**: PyMCを用い、波及構造を「地域」と「産業」の交差効果で分解して推定。
