# Shikoku Economic Analysis (1985–2005)

## Project Overview
1985年から2005年までの20年間（計4時点）の地域間産業連関表を用い、四国地域の経済構造の質的変容を解明する研究プロジェクトです。
産業連関分析による構造記述と、MCMC（階層ベイズ）を用いた統計的推論を組み合わせ、バブル期から低成長期に至るサプライチェーンの変容を定量化しています。

## Research Background & Novelty
* **20年にわたる長期時系列分析の希少性**
  地域間産業連関表を用いた分析の多くは単一時点の断面的分析です。本研究ではS60, H2, H7, H17の4時点について一貫した部門統合を行い、20年間の構造変化を追跡しました。この規模の長期時系列分析は、先行研究でも例のない独自の試みです。
* **産業間結合の質的変容の抽出**
  単なる取引額の増減ではなく、産業間の「経済的距離」を測るAPL指標を用いることで、サプライチェーンの効率化や希薄化といった構造的な変化を捉えています。
* **階層ベイズによる波及構造の要因分解**
  決定論的な指標算出に留まらず、交差効果モデルを導入。産業間の波及効果が「地域の特性」によるものか「産業の特性」によるものかを確率的に分離して推定しています。

## Methodologies
### 1. APL (Average Propagation Length)
産業間の「経済的な距離（＝サプライチェーンの長さ）」を測定する指標です。ある部門への需要が、何段階（何部門）を経て対象部門に波及するかを算出します。
* **Insight**: 1985年から2005年にかけてのAPLの変化を追うことで、四国経済におけるサプライチェーンの短縮化や、産業間結合の質の変化を明らかにします。

### 2. Localization Process
地域外への経済漏出を考慮し、輸入（域外流入）を控除した国産化行列を構築。
* **Model**: $$A_{domestic} = \text{diag}(d) A_{total}$$
* 地域内での真の経済波及を評価するための必須工程として実装しています。

### 3. Hierarchical Bayesian Modeling (Cross-Effect Model)
PyMCを用い、産業間の波及係数が持つばらつきを「地域要因」と「産業要因」に分解。
* **Why HBM?**: 地域特有の文脈と、全国共通の産業構造トレンドを分離し、波及構造の決定要因を特定します。

## Analysis Pipeline
1. **Data Preparation**: 1985-2005年の部門統合、統計データのクレンジング。
2. **Structural Analysis**: 輸入除去処理およびAPL指標による構造記述。
3. **Statistical Inference**: 階層ベイズモデルによる波及構造の要因分解。
4. **Visualization**: 分析結果の空間的な図示（QGIS連携）。
