# Data Preparation Guide

本プロジェクトでは、経済産業省が公表している「地域間産業連関表」の統計データを使用しています。
データの二次配布を避けるため、生データファイル（.xlsx）は本リポジトリに含まれていません。
以下の手順に従ってデータを取得し、指定のディレクトリに配置してください。

## 1. 必要となる統計データ
本分析では、1985年から2005年にわたる計4時点のデータを対象としています。

| 対象年 | 典拠統計名 | ファイル名 (リポジトリ内) |
| :--- | :--- | :--- |
| **昭和60年 (1985)** | 昭和60年 地域間産業連関表 | `S60.xlsx` |
| **平成2年 (1990)** | 平成2年 地域間産業連関表 | `H2.xlsx` |
| **平成7年 (1995)** | 平成7年 地域間産業連関表 | `H7.xlsx` |
| **平成17年 (2005)** | 平成17年 地域間産業連関表 | `H17.xlsx` |

## 2. 入手先
データは、経済産業省の「地域間産業連関表」の公式ページよりダウンロードしてください。

* **経済産業省 HP**: [地域間産業連関表 過去のデータ](https://www.meti.go.jp/statistics/tyo/tiikiio/index.html)

## 3. ディレクトリ構造
ダウンロードしたファイルは、以下の構造に従って配置してください。

```text
data/
├── raw/                      # ← ここにダウンロードした生データを配置
│   ├── S60.xlsx
│   ├── H2.xlsx
│   ├── H7.xlsx
│   └── H17.xlsx
└── mapping/                  # 部門統合用マッピング表（本リポジトリに同梱）
    └── 産業分類統一対応表_S60_H2_H7_H17.xlsx
