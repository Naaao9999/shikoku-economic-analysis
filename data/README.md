# Data Preparation Guide

本プロジェクトでは、経済産業省が公表している「地域間産業連関表」の統計データ、および地図描画用の境界データを使用しています。
データの二次配布を避けるため、生データファイルおよび地図データは本リポジトリに含まれていません。
以下の手順に従ってデータを取得し、指定のディレクトリに配置してください。

## 1. 必要となるデータ
本分析では、1985年から2005年にわたる計4時点の統計データと、空間分析用のGeoJSONデータを使用します。

| カテゴリ | 対象年 / データ名 | ファイル名 (推奨) |
| :--- | :--- | :--- |
| **統計データ** | 昭和60年 (1985) 地域間産業連関表 | `S60.xlsx` |
| **統計データ** | 平成2年 (1990) 地域間産業連関表 | `H2.xlsx` |
| **統計データ** | 平成7年 (1995) 地域間産業連関表 | `H7.xlsx` |
| **統計データ** | 平成17年 (2005) 地域間産業連関表 | `H17.xlsx` |
| **地図データ** | 日本47都道府県の境界データ | `prefectures.geojson` |

## 2. 入手先

### 統計データ（地域間産業連関表）
経済産業省の公式ページより、各年次のExcelファイルをダウンロードしてください。
* **経済産業省 HP**: [地域間産業連関表 過去のデータ](https://www.meti.go.jp/statistics/tyo/tiikiio/index.html)

### 地図データ（GeoJSON）
以下のサイトから、都道府県境界のGeoJSONファイルを取得してください。
* **Japonyol.net**: [47都道府県のGeoJSONデータ](https://japonyol.net/editor/article/47-prefectures-geojson.html)
  * サイト内の「47都道府県のGeoJSONファイル」をダウンロードし、（必要に応じて）ファイル名を `prefectures.geojson` に変更して使用してください。

## 3. ディレクトリ構造
ダウンロードしたファイルは、プロジェクトのルートディレクトリを基準として、以下の構造に従って配置してください。

```text
.
├── data/
│   ├── raw/                      # ← ここにダウンロードした統計(xlsx)を配置
│   │   ├── S60.xlsx
│   │   ├── H2.xlsx
│   │   ├── H7.xlsx
│   │   └── H17.xlsx
│   └── mapping/                  # マッピング・境界データ
│       ├── 産業分類統一対応表_S60_H2_H7_H17.xlsx
│       └── prefectures.geojson   # ← ここにダウンロードしたGeoJSONを配置
└── output/                       # 分析結果の出力先
